# 🚗 Hipódromo Despachante - Website Institucional

Site institucional moderno, responsivo e profissional para a empresa Hipódromo Despachante, especializada em documentação veicular.

## 📋 Sobre o Projeto

Website desenvolvido com HTML5, CSS3 e JavaScript puro, seguindo as melhores práticas de desenvolvimento web moderno. O site apresenta design elegante, clean e totalmente otimizado para dispositivos móveis.

### Design
- ✅ Layout moderno e profissional
- ✅ Identidade visual baseada nas cores da marca (#003C8F e #4DA3FF)
- ✅ Efeitos de glassmorphism e sombras suaves
- ✅ Animações suaves e transições elegantes
- ✅ Totalmente responsivo (mobile-first)

### Funcionalidades
- ✅ Header fixo com efeito blur

- ✅ Navegação suave entre seções

## 🚀 Como Usar

### 1. Adicionar o Logo

1. Salve o logo da empresa como `logo.png` na pasta `assets/`
2. Formato recomendado: PNG com fundo transparente
3. Dimensões sugeridas: 200x80px (ou manter proporção)

### 2. Abrir o Site

Simplesmente abra o arquivo `index.html` em qualquer navegador moderno:

- Google Chrome (recomendado)
- Mozilla Firefox
- Safari
- Microsoft Edge

### 3. Hospedagem

Para publicar o site online, você pode usar:

- **GitHub Pages** (gratuito)
- **Netlify** (gratuito)
- **Vercel** (gratuito)
- Qualquer servidor web (Apache, Nginx, etc.)

## 🔧 Personalização

### Alterar Cores

Edite as variáveis CSS no arquivo `style.css`:

```css
:root {
    --primary-blue: #003C8F;
    --secondary-blue: #4DA3FF;
    /* ... outras cores */
}
```

### Alterar Conteúdo

Edite o arquivo `index.html` diretamente. O código está bem comentado e organizado por seções.

### Alterar Comportamentos

Edite o arquivo `script.js` para modificar:
- Velocidade do carrossel (padrão: 5000ms)
- Animações
- Efeitos de scroll
