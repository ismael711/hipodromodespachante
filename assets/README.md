# Assets Folder

## Logo Instructions

Please save the Hipódromo Despachante logo images in this folder with the following names:

- **logo.png** - Main logo (recommended size: 200x80px or similar aspect ratio)
  - This will be used in the header and footer
  - Should have a transparent background
  - PNG format preferred for quality

## Image Recommendations

### Logo Specifications:
- Format: PNG with transparent background
- Recommended dimensions: 200x80px (or maintain aspect ratio)
- File size: Keep under 100KB for optimal loading
- Color: The logo should work well on white backgrounds

### How to Add the Logo:

1. Save your logo file as `logo.png` in this `assets` folder
2. The website will automatically display it in:
   - Header (top navigation)
   - Footer

### Current Logo References:

The logo images provided show:
- Blue gradient wing design
- "HIPODROMO" text in black
- "DESPACHANTE" text in blue
- Clean, modern, professional appearance

### Alternative:

If you don't have the logo file yet, you can:
1. Use the provided logo images from the task
2. Convert them to PNG format
3. Save as `logo.png` in this folder

The website is already configured to use `assets/logo.png` for the logo display.
